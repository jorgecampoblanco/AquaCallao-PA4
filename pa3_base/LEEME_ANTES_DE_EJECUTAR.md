# Advertencia sobre scripts de PA3

Scripts de PA3 copiados sin modificar; varios incluyen procedimientos y bloques de pruebas que insertan, actualizan o eliminan datos.

01_CrearTablas.sql crea la base AquaCallao y datos iniciales, por lo que no debe ejecutarse si ya existe una base con ese nombre. Usar una instancia local de práctica. No ejecutar automáticamente todas las pruebas sobre una base compartida. Verificar primero dependencias y resultados reales en SSMS.
